━━━━━━━━━━ 一、專案目標 ━━━━━━━━━━

- 做一個自己用的英文單字卡程式，取代 Anki（Anki 字太小、不能放大、難用）。
- 每天打開，程式自動挑出今天要背的卡；翻牌、自己評分；程式依分數排好下次什麼時候再考。
- 單字來源：大考中心第 1～6 級（約 6,000 字），之後可以自己新增單字。
- 給所有人用：每個人程度不同，先做單字量測試，依結果分配要學哪些級別。
- 形式：在自己電腦上跑的網頁（單機版），v1.0 打包成雙擊就能安裝的程式，給朋友下載使用。
- 功能越來越多，每個畫面都有「？ 幫助」小助手，教使用者怎麼操作。


━━━━━━━━━━ 二、功能架構 ━━━━━━━━━━

英文單字卡
首頁（v1.0：顯示今天要複習幾張、各功能入口、回饋按鈕）
每個畫面角落：「？ 幫助」小助手按鈕（v1.0）
│
├── 1. 單字庫　　　　　　　　　　　　　　　　　　　　　【library.py】
│   負責：儲存所有單字。大考中心匯入、手動新增的，全部統一放這裡
│   │
│   ├── 瀏覽單字　　　　　　　　　　　　　　　　　　　　v0.1
│   │   操作：選級別 → 看這一級的所有單字和複習狀態
│   │
│   ├── 匯入單字檔　　　　　　　　　　　【importer.py】v0.1
│   │   負責：把大考中心單字檔變成卡片
│   │   操作：選檔案 → 讀取 → 跳過重複 → 顯示匯入幾張
│   │
│   ├── 新增單字　　　　　　　　　　　　【adder.py】　v1.1
│   │   負責：手動加入新字，重複就跳通知，不加入重複的單字
│   │   操作：輸入英文 → 檢查重複 → 輸入中文、例句 → 儲存
│   │
│   ├── 搜尋　　　　　　　　　　　　　　　　　　　　　　v1.1
│   │   操作：輸入英文 → 顯示這張卡和它的複習進度
│   │
│   ├── 編輯、刪除　　　　　　　　　　　　　　　　　　　v1.1
│   │   操作：找到卡片 → 修改中文、例句，或刪除
│   │
│   ├── 已熟練打勾 ✓／取消打勾　　　　　　　　　　　　v0.3
│   │   負責：已經很熟的字打勾，不再出現在複習；之後覺得不熟可以取消
│   │   操作：找到卡片 → 打勾或取消打勾
│   │
│   ├── 收藏星號、暫停卡片、自訂標籤　　　　　　　　　　v1.3
│   │   操作：在卡片上打星號／暫停／加標籤（例如「投資」「遊戲」）
│   │
│   └── 易混淆字對照　　　　　　　　　　　　　　　　　　v2.1
│       操作：把容易搞混的字放在一起比較（例如 quite／quiet）
│
├── 2. 單字量測試　　　　　　　　　　　　　　　　　　　v0.3
│   負責：了解使用者程度，決定新卡從哪些級別出
│   │
│   ├── 程度測驗　　　　　　　　　　　　【placement_test.py】
│   │   畫面註明：相對快速，但有誤差
│   │   操作：選長度（簡短 30／一般 60／詳細 120 題）→ 每題看英文 → 會／不會
│   │　　　　→ 會的顯示中文確認 → 做完顯示各級正確率長條圖
│   │   結果：依正確率決定之後新卡怎麼分配（規則見《複習規則》第八點）；可以重測
│   │
│   └── 快速篩選　　　　　　　　　　　　【screening.py】
│       畫面註明：比較慢，但具體
│       操作：看英文 → 按「會／不會」→ 會的顯示中文確認（可以改回不會）→ 下一張
│　　　　　　→ 隨時可以離開，下次接著篩
│       結果：會 → 排 30 天後複習；不會 → 留在新卡，照每日新卡數慢慢學
│
├── 3. 今日複習　　　　　　　　　　　　　　　　　　　　【review.py】v0.2
│   負責：挑出今天要考的卡，翻牌評分，排好下次複習日
│   操作：看英文 → 按「看答案」→ 看中文和例句 → 評 1～5 分
│　　　　（1 完全不會／2 有印象但錯了／3 想很久才想到／4 想得到／5 直覺）
│　　　　→ 1、2 分放回最後重考 → 全部過關 → 顯示今天完成
│   │
│   ├── 新卡依單字量測試結果分配到各級　　　　　　　　　v0.3
│   ├── 複習時直接打勾「已熟練」　　　　　　　　　　　　v0.3
│   ├── 復原上一個評分　　　　　　　　　　　　　　　　　v1.1
│   ├── 只考某一級／某個標籤／星號　　　　　　　　　　　v1.3
│   ├── 中翻英翻牌（看中文、想英文）　　　　　　　　　　v1.3
│   └── 唸出英文發音　　　　　　　　　　　　　　　　　　v2.0
│
├── 4. 其他測驗方式　　　　　　　　　　　　　　　　　　【quiz.py】v3.0
│   負責：用不同方式測驗，包含拼字（判斷「已掌握」用）
│   └── 選擇題、拼字、聽寫、配對小遊戲、圖片
│
├── 5. 統計　　　　　　　　　　　　　　　　　　　　　　【stats.py】
│   ├── 總卡數、今天要考幾張、剩幾張新卡、今天複習幾分鐘　v1.2
│   ├── 各級進度、困難次數、連續學習天數　　　　　　　　v1.2
│   ├── 熟悉單字量（看到英文就知道中文）　　　　　　　　v1.2
│   │   規則：最近一次評 5 分、或篩選／測驗答「會」、或已熟練打勾
│   ├── 常錯單字　　　　　　　　　　　　　　　　　　　　v1.2
│   │   統計頁：顯示總數和錯最多的前 5 個 →「查看全部」
│   │   獨立頁面：答錯 4 次以上的全部單字，可以依答錯次數、級別排序篩選
│   ├── 學習紀錄圖表　　　　　　　　　　　　　　　　　　v2.2
│   └── 已掌握單字量（會拼）　　　　　　　　　　　　　　v3.0
│       規則：拼字測驗答對過，詳細規則 v3.0 再訂
│
├── 6. 文件夾　　　　　　　　　　　　　　　　　　　　　【docs_viewer.py】v1.1
│   負責：在網頁上直接看本專案 docs/ 裡的文件
│   操作：點進去 → 選資料夾 → 打開文件閱讀
│
├── 7. 小助手（每個畫面的「？ 幫助」）　　　　　　　【helper.py】v1.0
│   負責：教使用者怎麼操作各個功能
│   操作：點「？ 幫助」→ 小助手問需要什麼幫助、列出選項 → 選一個
│　　　　→ 顯示對應的操作步驟和畫面截圖
│   說明：v1.0 先涵蓋 v1.0 的功能；之後每加一個功能就補上說明
│
├── 8. 設定　　　　　　　　　　　　　　　　　　　　　　【settings.py】
│   ├── 字體大小、背景顏色、版面、介面語言　　　　　　　v1.2
│   ├── 每日新卡數、複習天數和倍數　　　　　　　　　　　v1.2
│   ├── 語速快慢　　　　　　　　　　　　　　　　　　　　v2.0
│   └── 備份、還原　　　　　　　　　　　　　　　　　　　v2.1
│
└── 背後共用（使用者看不到）
    ├── 存檔、讀檔　　　　　　　　　　　【storage.py】　v0.1
    ├── 排程計算　　　　　　　　　　　　【scheduler.py】v0.2
    │   └── 複習卡太多時新卡減半、間隔隨機 ±10%　　　　v1.3
    └── 預設值　　　　　　　　　　　　　【config/】　 v0.2 起


━━━━━━━━━━ 三、發行與回饋 ━━━━━━━━━━

- v1.0：打包成 Windows 安裝檔（雙擊安裝、建桌面捷徑），放在 GitHub 的 Releases 讓朋友下載
- v1.1：Mac 版
- 回饋：首頁放「回饋」按鈕，打開 Google 表單（不需要帳號，朋友的朋友也能填）
- 每個人的單字庫和進度存在自己電腦，不需要帳號登入
