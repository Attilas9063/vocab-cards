━━━━━━━━━━ 一、版本號的規則 ━━━━━━━━━━

格式：主版本.次版本.修正版，例如 v1.2.3

- 主版本（第一個數字）：大改，跟舊的差很多
- 次版本（第二個數字）：加了新功能，舊的照樣能用
- 修正版（第三個數字）：只修錯誤，沒有新功能
- 前面的數字加 1，後面的歸零：v1.3.5 加新功能 → v1.4.0
- 0.x：開發中的版本，能跑但功能不完整
- 1.0：第一個正式版，功能完整到可以日常使用（可以把 Anki 換掉）

每完成一版，在 GitHub 上把那個存檔點標上版本號（叫 tag 標籤），之後找得到。


━━━━━━━━━━ 二、各版本 ━━━━━━━━━━

【v0.1】看得到自己的單字庫
- 安裝 Flask、建立資料夾架構
- 存檔、讀檔（storage.py）
- 匯入大考中心單字檔（importer.py）
- 瀏覽單字：依級別看（library.py ＋ 第一個網頁）

【v0.2】開始能每天背
- 排程計算（scheduler.py）：依《複習規則》排下次複習日
- 預設值（config/review.py）
- 今日複習（review.py ＋ 翻牌畫面，含 JavaScript 樣板）：
  到期的卡 ＋ 新卡（每天 10 張，先從第 1 級依序出）、翻牌、評 1～5 分、答錯重考

【v0.3】知道自己的程度
- 單字量測試：
  程度測驗（placement_test.py，30／60／120 題、各級正確率長條圖）
  快速篩選（screening.py）
- 新卡依測驗結果分配到各級（config/allocation.py）
- 已熟練打勾 ✓／取消打勾（複習時、單字庫裡都可以）

【v1.0】第一個正式版
- 首頁：今天要複習幾張、各功能入口、回饋按鈕（打開 Google 表單）
- 小助手：每個畫面的「？ 幫助」，涵蓋 v1.0 的所有功能（helper.py）
- 整體測試、修正
- 打包成 Windows 安裝檔，放上 GitHub Releases

【v1.1】好用的小功能
- Mac 版
- 新增單字（檢查重複）
- 搜尋、編輯、刪除
- 復原上一個評分
- 文件夾（在網頁上看 docs/ 的文件）

【v1.2】統計和設定
- 統計：總卡數、今天幾張、剩幾張新卡、複習幾分鐘、各級進度、
       困難次數、連續學習天數、熟悉單字量
- 常錯單字頁（答錯 4 次以上，獨立頁面，可排序篩選）
- 設定：字體大小、背景顏色、版面、介面語言、每日新卡數、複習天數和倍數

【v1.3】整理自己的字
- 收藏星號、暫停卡片、自訂標籤
- 只考某一級／某個標籤／星號
- 中翻英翻牌
- 複習卡太多時新卡減半、間隔隨機 ±10%

【v2.0】發音
- 唸出英文發音、設定語速

【v2.1】輔助工具
- 易混淆字對照
- 備份、還原

【v2.2】學習紀錄圖表

【v3.0】其他測驗方式
- 選擇題、拼字、聽寫、配對小遊戲、圖片
- 已掌握單字量（會拼）


━━━━━━━━━━ 三、有空再做（不排版本）━━━━━━━━━━

- 線上版：部署到雲端、資料庫、獨立網址
- 帳號登入：線上版時，每個人有自己的單字庫和進度
- 回饋頁自動送到 GitHub Issues
- 手機 App、手機版面、每日提醒


━━━━━━━━━━ 四、版本調整的原則 ━━━━━━━━━━

- v1.0 一定要做完；v1.1 之後做到哪裡，看到時候想不想繼續。
- 每一版新增的功能，都要補小助手的說明（v1.0 起）。
- 某一版預估太久（見《時程規劃》），就拆成兩三個小版本。
- 調整版本內容時，同步更新《架構規劃》的版本標記，並在《決策紀錄》寫下理由。
